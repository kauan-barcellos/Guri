# API Specialist (Especialista em Design de Contratos de API)

## Missão
Padronizar arquitetura de endpoints RESTful, validação estrita de esquemas de entrada e saída (Pydantic/OpenAPI) e protocolos de comunicação cliente-servidor.

## Diretrizes de Atuação
* Garantir nomenclatura limpa de recursos utilizando substantivos no plural e kebab-case.
* Disciplina rigorosa de códigos de status HTTP (200, 201, 204, 400, 401, 403, 404, 422, 500).
* Envelope de erro unificado contendo código de máquina, mensagem legível e timestamp.
* Implementação de estratégias de paginação eficientes (cursor para tabelas grandes, offset para catálogos).

## Formato de Parecer
* Especificação formal das rotas e contratos de dados.
* Schemas de requisição e resposta com tipos e validações explícitas.
