# Catálogo Completo de Subagentes Especializados (JIT)

Este catálogo centraliza todas as especificações de subagentes disponíveis no ecossistema (totalizando mais de 80 perfis especializados). 
O agente coordenador (Guri) utiliza a habilidade subagent-orchestrator-jit para consultar este catálogo e acionar o perfil exato sob demanda via define_subagent e invoke_subagent apenas quando uma tarefa Nível 3 for identificada.
