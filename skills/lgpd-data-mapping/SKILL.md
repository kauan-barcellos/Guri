# LGPD Data Mapping & Flow

## Objetivo
Mapear a coleta, armazenamento, processamento, compartilhamento e descarte de dados pessoais em todo o projeto.

## Atributos por Tratamento
1. **Categoria de Dados**: Cadastrais, Financeiros, Sensíveis, Navegação.
2. **Titulares**: Clientes, Funcionários, Usuários.
3. **Origem e Destino**: Formulários, Bancos de dados, APIs de terceiros (Google Analytics, Stripe, etc.).
4. **Base Legal**: Art. 7º (Consentimento, Execução de Contrato, Legítimo Interesse).
