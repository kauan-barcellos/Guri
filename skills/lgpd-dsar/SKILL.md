# LGPD DSAR — Direitos dos Titulares

## Objetivo
Garantir o atendimento técnico automatizado ou semi-automatizado às solicitações de acesso, exclusão, correção e portabilidade dos dados do titular.

## Direitos do Art. 18
- **Confirmação e Acesso**: Endpoint/mecanismo para o usuário baixar seus dados em formato legível (JSON/CSV).
- **Eliminação (Right to be Forgotten)**: Anonimização ou exclusão definitiva do banco de dados (respeitando prazos legais de guarda).
- **Revogação do Consentimento**: Opção de 1-clique para cancelar autorizações de tratamento de dados.
